How to Play

Take turns placing X and O marks on the grid. On a 3x3 board, line up 3 marks in a row, column, or diagonal to win. On 4x4 and 5x5 boards you need 4 in a row instead. If the grid fills with no winner, it's a draw.

Game Modes

2 Player - take turns on the same device.

Vs CPU - play against the computer at Easy, Medium, or Hard difficulty. On the 3x3 board, Hard plays perfectly and cannot be beaten, only tied. On 4x4/5x5, an exhaustive perfect search isn't practical, so Hard instead uses a strong multi-move lookahead - very tough, but not unbeatable.

Board Size

Choose 3x3, 4x4, or 5x5 from the Settings page. The size you pick applies to the next game you start (2 Player or Vs CPU).

Pause Menu

Press 0 or the Left Softkey during a game to pause. From there you can resume, restart, open Settings/Help/About, or return to the Main Menu.
